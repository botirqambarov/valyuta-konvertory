# Soliq чек тахрирлаш боти

Excel файлдаги маълумотлар асосида **my3.soliq.uz** сайтига кириб, корхонанинг
нотўғри урилган чекларини автоматик тахрирлайди. Чек миқдори ва МХИК коди
автоматик ўзгартирилади, тўлов суммаси текширилади, ZIP юкланади ва CAPTCHA
**Google Gemini API** ёрдамида ечилади.

---

## Янгиликлар

- **Gemini API** (Anthropic Claude ўрнига) — арзонроқ ва тезроқ.
- **API key кэш** — иккита режим:
  - **Тайёр (default) кэлит** — иловага қўшилган. Клиент ҳеч нима киритмасдан ишлатиши мумкин.
  - **Ўз кэлити** — клиент GUI'да ўзининг Gemini API key'ини киритиб, "Эслаб қол" белгилаб қўйса, кейинги ишга туширишда қайта киритиш керак эмас.
- **Тун режими** — ҳақиқий қора (true black) интерфейс. Юқоридаги "🌙 Тун режими" белгисидан ўтасиз/ўчирасиз.

---

## Ўрнатиш

1. **Python 3.10+** ўрнатинг (Windows/macOS — расмий python.org дан).
   * Linux да: `sudo apt install python3-tk` (tkinter учун).
2. Виртуал муҳит яратиб, талабларни ўрнатинг:
   ```bash
   python -m venv .venv
   source .venv/bin/activate    # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   playwright install chromium
   ```

3. **Gemini API key** олинг (https://aistudio.google.com/app/apikey).
   Қуйидаги усуллардан бирини танланг:
   * **A) Тайёр (default) кэлит** — иловани клиентларга тарқатишдан олдин,
     `soliq_bot/_default_key.py` файлига ўз Gemini кэлитингизни ёзинг:
     ```python
     DEFAULT_GEMINI_API_KEY = "AIza...."
     ```
     Шу файл `git`'га юкланмайди (`.gitignore` да). Иловани ZIP қилиб тарқатсангиз — клиент ҳеч нима киритмасдан ишлай олади.
   * **B) Ўз кэлитим (клиент)** — клиент GUI'нинг "Gemini API key" блокидан **"Ўз кэлитимни ишлатаман"** ни танлайди, кэлитни киритади ва **"Кэлитни эслаб қол"** ни белгилайди. Кэлит `~/.soliq_bot/custom_key.txt` файлига сақланади.
   * **C) Муҳит ўзгарувчиси** — `GEMINI_API_KEY` муҳит ўзгарувчиси ҳам default кэлит сифатида тан олинади (агар `_default_key.py` бўш бўлса).

4. **e-IMZO Java ўрнатинг** (my3.soliq.uz сертификат билан ишлатиш учун).

---

## Ишга тушириш

```bash
python run.py
```

GUI очилади. Қуйидагиларни киритинг:

| Майдон            | Тавсиф                                                           |
|-------------------|------------------------------------------------------------------|
| Логин тури        | "Корхона" ёки "ЯТТ"                                              |
| Корхона номи      | Ҳақиқий корхона номи (қидирув бўйича топилади)                   |
| Excel файл        | Тахрирланадиган чеклар рўйхати                                   |
| ZIP файл          | Ҳар бир чекка юкланадиган `asos.zip`                             |
| Воркер сони       | 1-5 (параллел ишлаш учун)                                        |
| Gemini API key    | "Тайёр (default)" ёки "Ўз кэлитим" — танлаб киритинг             |

**Старт** тугмаси босилгач:

1. Ҳар бир воркер учун алоҳида браузер очилади
2. Логин формаси тўлдирилиб, "Кириш" босилади
3. **Java парол ойнаси очилгач** — паролни қўлда териб, GUI да
   "Парол киритилди" тугмасини босинг (ҳар воркер учун алоҳида)
4. Бот қолган барча ишни автоматик бажаради

## API key қаерда сақланади?

| Манба                          | Файл / Жой                          | Изоҳ                                        |
|--------------------------------|--------------------------------------|---------------------------------------------|
| Тайёр (default) кэлит          | `soliq_bot/_default_key.py`          | Ишлаб чиқувчи / тарқатувчи қўяди (gitignored) |
| Муҳит ўзгарувчиси (fallback)   | `GEMINI_API_KEY` (env)               | Default бўш бўлса ишлатилади                |
| Клиент киритган кэлит (кэш)    | `~/.soliq_bot/custom_key.txt`        | Файл фақат фойдаланувчига ўқилади (chmod 600) |
| GUI/тема созламалари           | `~/.soliq_bot/ui_prefs.json`         | Тун режими, охирги танланган режим           |

Кэшни ўчириш учун GUI'да **"Кэшни ўчириш"** тугмасини босинг.

## Excel формати

Устунлар (Cyrillic):

| ФМ рақами | Чек рақами | Махсулот номи | Миқдори | Нархи | Махсулот коди |
|-----------|------------|---------------|---------|-------|---------------|
| ...       | ...        | ...           | ...     | ...   | ...           |

* Битта чек бир неча қатордан иборат бўлиши мумкин (масалан, 1 чек = 4 та маҳсулот).
* Бот (ФМ рақами + Чек рақами) жуфтлиги бўйича автоматик гуруҳлайди.

## Иш кетма-кетлиги (батафсил)

1. **Логин:** my3.soliq.uz/login → корхона қидирилади → "Кириш"
2. **Java парол:** қўлда → "Парол киритилди"
3. **Чекни топиш:** ФМ дропдан танланади + Чек рақами киритилади + "Қидириш"
4. **Тахрирлаш:** "Батафсил" → "Таҳрирлаш"
5. **Қаторларни мослаштириш:** сайтдаги ҳар қатор → Excel қатори:
   - Асосий калит: Сумма (Нархи)
   - Қўшимча: ном ўхшашлиги
6. **Тахрирлаш:** янги Миқдори ва МХИК код киритилади
7. **Тўлов текшируви:** жами ≠ нақд + терминал бўлса → терминал=0, нақд=жами
8. **ZIP юклаш**
9. **CAPTCHA:** Gemini API орқали ечилади
10. **Сақлаш:** "Сақлаш" тугмаси

---

## Параллел ишлаш

* 1-5 та воркер бир вақтда ишлайди
* Чеклар (ФМ + Чек) жуфтлиги бўйича round-robin тарзда тақсимланади
* Ҳар воркер учун **алоҳида браузер профили** (`~/.soliq_bot_profiles/worker_N`)
  → e-IMZO сертификатлари аралашмайди

## Танишмасликлар (Селекторлар)

`my3.soliq.uz` саҳифасининг HTML тузилиши вақт ўтиши билан ўзгариши мумкин.
Агар бот элементни топа олмаса (хато: timeout, "не найдено" ва ҳ.к.), қуйидаги
файлдаги селекторларни созланг:

`soliq_bot/config.py` → `Selectors` синфи

Кўпинча бу селекторларни DevTools (F12) орқали топиб, шу файлда янгилаш керак.

## Огоҳлантириш

* Бот **браузерни кўриниб турадиган** (headless эмас) режимда очади — Java
  пароли ойнаси билан ишлаш учун.
* Селекторлар спецификация бўйича ёзилган. Ҳақиқий сайтда сал фарқ бўлиши
  мумкин — биринчи марта ишга тушириб, лог ойнасини кузатиб боринг.
* `_default_key.py` файлидаги Gemini кэлит **ҳар бир тарқатилган нусхада** клиентга
  ўтади. Уни git'га юкламанг ва ошкор қилмасликка ҳаракат қилинг.
